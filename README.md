# Operation Low-Poly

第二次世界大戦をモチーフにした、PS1風ローポリ表現のブラウザTPSプロトタイプです。

## 遊び方

1. `index.html` をブラウザで開く。
2. `WASD` で移動、`←→` で旋回、`Space` で射撃。
3. 敵を倒すとスコア加算。全滅で次ウェーブへ。
4. HPが0になるとゲームオーバー。`R` でリスタート。

## ファイル構成

- `index.html` : UIとキャンバス。
- `styles.css` : PS1風HUD・画面スタイル。
- `game.js` : ゲームロジック（移動、射撃、敵AI、ウェーブ管理）。
